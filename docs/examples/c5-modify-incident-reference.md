# C5 Modify Incident (Static Reference)

This reference example is a static visual contract for a dense CAD operator dialog and intentionally includes no API wiring, React Query usage, or incident mutation behavior.

## Usage

```tsx
import { C5ModifyIncidentReference } from "@condor/classic-ui";

export function Example() {
  return <C5ModifyIncidentReference />;
}
```
