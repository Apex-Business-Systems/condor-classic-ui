# Condor Classic UI Fonts

Only fonts with clear redistribution rights may be committed here.

For each bundled font, document:

- Font name
- Source
- License
- License URL or included license text
- Original filename
- Converted filename, if converted to WOFF2
- Conversion tool/process

Do not commit original Microsoft Windows, Apple Mac OS, or proprietary UNIX/CDE fonts unless redistribution rights are confirmed.
